# Función reutilizable para presentar tablas con formato académico
mostrar_tabla <- function(datos, titulo = NULL, digitos = 2) {
  tabla <- as.data.frame(datos)

  # Encabezados más claros para las variables utilizadas en el taller
  etiquetas <- c(
    xi = "Valor (xi)",
    fi = "Frecuencia (fi)",
    fi_xi = "Producto (xi × fi)",
    fi_sobre_xi = "Frecuencia / valor",
    fi_log_xi = "Frecuencia × ln(valor)",
    Li = "Límite inferior",
    Ls = "Límite superior",
    mi = "Marca de clase",
    fi_mi = "Frecuencia × marca",
    Indicador = "Indicador",
    Resultado = "Resultado",
    Resultado_dias = "Resultado (días)",
    Medida = "Medida estadística",
    km_h = "Velocidad (km/h)",
    Total_funcionarios = "Total de funcionarios",
    Media_ponderada = "Media ponderada",
    Media_datos_expandidos = "Media de datos expandidos",
    Media_sin_ponderar_no_valida = "Media sin ponderar (no válida)",
    Media_armonica_ponderada = "Media armónica ponderada",
    Media_armonica_expandida = "Media armónica expandida",
    Media_aritmetica_ponderada = "Media aritmética ponderada",
    Factor_geometrico_promedio = "Factor geométrico promedio",
    Tasa_porcentual_promedio = "Tasa promedio (%)",
    Verificacion_expandida = "Verificación expandida",
    Media_miles_de_pesos = "Media (miles de pesos)",
    Media_en_pesos = "Media (pesos)",
    Factor_geometrico_aproximado = "Factor geométrico aproximado",
    Tasa_geometrica_porcentual = "Tasa geométrica (%)",
    Media_aritmetica_de_factores = "Media aritmética de factores"
  )

  nombres <- names(tabla)
  nombres[nombres %in% names(etiquetas)] <- etiquetas[nombres[nombres %in% names(etiquetas)]]
  names(tabla) <- nombres

  knitr::kable(
    tabla,
    format = "html",
    caption = titulo,
    digits = digitos,
    align = "c",
    row.names = FALSE,
    escape = TRUE,
    format.args = list(decimal.mark = ",", big.mark = ".")
  ) |>
    kableExtra::kable_styling(
      bootstrap_options = c("striped", "hover", "condensed", "responsive"),
      full_width = FALSE,
      position = "center",
      font_size = 14
    ) |>
    kableExtra::row_spec(
      0,
      bold = TRUE,
      color = "#FFFFFF",
      background = "#17365D"
    ) |>
    kableExtra::column_spec(
      1,
      bold = TRUE,
      color = "#17365D"
    )
}

Introducción

Este informe resuelve los diez ejercicios del taller sobre media aritmética, media armónica y media geométrica. Se presentan las fórmulas, el procedimiento reproducible en R y la interpretación de cada resultado en el contexto de la gestión pública.

Los datos del taller son simulados con fines didácticos. En los ejercicios agrupados por intervalos, las marcas de clase representan los valores de cada intervalo; por ello, los resultados son aproximaciones.

Preparación del entorno

El cálculo principal se realiza con R base. Los paquetes psych, DescTools y dplyr se utilizan para las verificaciones y la presentación de tablas.

Ejercicio 1. Tiempos de respuesta a solicitudes

Datos: 3, 5, 4, 6, 8, 4, 7, 5, 3, 9, 6 y 4 días hábiles.

La media aritmética se calcula sumando los tiempos y dividiendo entre el número de solicitudes:

[ {x}= ]

donde (x_i) representa el tiempo de respuesta de cada solicitud y (n) el total de solicitudes.

Ver código 
dias <- c(3, 5, 4, 6, 8, 4, 7, 5, 3, 9, 6, 4)

media_dias <- mean(dias)
media_manual <- sum(dias) / length(dias)

mostrar_tabla(data.frame(

  Resultado_dias = c(media_dias, media_manual)
), "Tabla 1. Comparación de medias del tiempo de respuesta", digitos = 4)
Tabla 1. Comparación de medias del tiempo de respuesta
Indicador Resultado (días)
Media con mean() 5,3333
Media manual 5,3333

Resultado: la media es 5,3333 días hábiles. Los dos procedimientos coinciden.

Interpretación: en promedio, la oficina tarda aproximadamente 5,33 días hábiles en responder una solicitud. La meta institucional es de cinco días; por tanto, el promedio supera la meta en 0,33 días (aproximadamente ocho horas laborales si se consideran jornadas de ocho horas). La media aritmética es pertinente porque se promedian tiempos expresados en la misma unidad y cada solicitud tiene el mismo peso.

Ejercicio 3. Crecimiento de la recaudación municipal

Tasas anuales: 6 %, 9 %, 12 %, 5 % y 10 %.

Las tasas porcentuales deben convertirse en factores multiplicativos. La media geométrica de los factores se transforma nuevamente en porcentaje:

G = \left[\prod_{i=1}^{n}\left(1+\frac{r_i}{100}\right)\right]^{\frac{1}{n}}

La tasa compuesta geométrica se calcula mediante:

r_G = (G-1)\times 100

Ver código 
tasas <- c(6, 9, 12, 5, 10)
factores <- 1 + tasas / 100

G_factor <- exp(mean(log(factores)))
tasa_compuesta <- (G_factor - 1) * 100
media_aritmetica_tasas <- mean(tasas)

mostrar_tabla(data.frame(
  Indicador = c("Factor geométrico promedio", "Tasa compuesta geométrica (%)",
                "Media aritmética de las tasas (%)"),
  Resultado = c(G_factor, tasa_compuesta, media_aritmetica_tasas)
), "Tabla 3. Resumen del crecimiento de la recaudación", digitos = 4)
Tabla 3. Resumen del crecimiento de la recaudación
Indicador Resultado
Factor geométrico promedio 1,0837
Tasa compuesta geométrica (%) 8,3694
Media aritmética de las tasas (%) 8,4000
Ver código 
# Verificaciones opcionales:
# psych::geometric.mean(factores)
# DescTools::Gmean(factores)

Resultado: factor geométrico promedio = 1,0836935; tasa anual compuesta = 8,3694 %; media aritmética = 8,4 %.

Interpretación: la recaudación propia tuvo una tasa anual compuesta promedio aproximada de 8,37 % durante el periodo. La media aritmética es 8,4 %, ligeramente superior. Pueden diferir porque el crecimiento se acumula multiplicativamente de un año al siguiente; por eso, para resumir tasas compuestas se utiliza la media geométrica de los factores y no el promedio aritmético directo de los porcentajes.

La media aritmética ponderada incorpora la frecuencia de cada valor:

\bar{x}_w = \frac{\sum_{i=1}^{k} x_i f_i}{\sum_{i=1}^{k} f_i}

La media armónica ponderada es:

H_w=\frac{N}{\sum_{i=1}^{k}\frac{f_i}{x_i}}

Ver código 
tabla_tasas <- tibble(
  xi = c(4, 5, 8, 10),
  fi = c(4, 6, 7, 3)
) |>
  mutate(fi_sobre_xi = fi / xi)

N_tasas <- sum(tabla_tasas$fi)
H_tasas <- N_tasas / sum(tabla_tasas$fi_sobre_xi)
A_tasas <- sum(tabla_tasas$fi * tabla_tasas$xi) / N_tasas

datos_tasas <- rep(tabla_tasas$xi, times = tabla_tasas$fi)
H_expandida <- length(datos_tasas) / sum(1 / datos_tasas)

mostrar_tabla(tabla_tasas, "Tabla 5. Frecuencia de tasas de procesamiento", digitos = 4)

# Verificación opcional:

Resultado: media armónica ponderada = 5,9259 expedientes por hora; media aritmética ponderada = 6,6 expedientes por hora. La expansión confirma la media armónica.

Interpretación y condición de uso: la media armónica es defendible si las observaciones representan tasas comparables bajo una misma unidad de exposición o si cada jornada tiene igual exposición temporal y el promedio que se desea construir corresponde a tasas por unidad de tiempo. Si las jornadas tienen duraciones diferentes, o si los grupos representan exposiciones distintas, se requieren los tiempos o exposiciones reales para construir una tasa global apropiada. La frecuencia por sí sola no garantiza esa condición.

La media geométrica ponderada es:

G_w=\exp\left(\frac{\sum_{i=1}^{k}f_i\ln(x_i)} {\sum_{i=1}^{k}f_i}\right)

La marca de clase es el punto medio del intervalo:

m_i=\frac{L_i+L_s}{2}

La media aproximada es:

\bar{x}\approx\frac{\sum_{i=1}^{k}f_i m_i}{N}

Ver código 
tabla_gasto <- tibble(

  Ls = c(200, 300, 400, 500, 600),

) |>
  mutate(
    mi = (Li + Ls) / 2,
    fi_mi = fi * mi

4 Integración y análisis

Ejercicio 9. Selección de la medida adecuada

Indicador de gestión Medida recomendada Justificación
Días que tardan los trámites en resolverse Media aritmética Resume el tiempo promedio cuando cada trámite tiene el mismo peso y se mide en días comparables.
Velocidad de vehículos que recorren distancias iguales Media armónica La velocidad es una razón entre distancia y tiempo; con distancias iguales, el tiempo varía inversamente con la velocidad.
Factores anuales de crecimiento de cobertura Media geométrica Los factores se encadenan multiplicativamente y deben ser positivos.

No es correcto aplicar una única media a todos los indicadores porque cada fenómeno tiene una estructura matemática distinta. La media aritmética resume cantidades aditivas, la armónica resulta adecuada para ciertas tasas con igual exposición y la geométrica para factores multiplicativos.

Indicadores adicionales propuestos:

  • Media aritmética: promedio de días hábiles para entregar licencias, certificados o respuestas a peticiones.
  • Media armónica: velocidad promedio de vehículos oficiales en recorridos de igual distancia entre sedes rurales.
  • Media geométrica: tasa anual compuesta de crecimiento de la población beneficiaria de un programa social.

Ejercicio 10. Informe breve de resultados

Informe de aplicación de medias estadísticas a la gestión pública

Objetivo. Aplicar las medias aritmética, armónica y geométrica a indicadores simulados de gestión pública, con el fin de resumir tiempos de atención, velocidades operativas, productividad y crecimiento de programas e ingresos.

Metodología. Se organizaron los datos en vectores y tablas de frecuencias en R. Para datos no agrupados se emplearon funciones como mean() y fórmulas directas. En datos agrupados se incorporaron las frecuencias como ponderaciones. En los intervalos se utilizaron las marcas de clase, por lo que los resultados se interpretan como aproximaciones.

Resultados principales. El tiempo promedio de respuesta fue de 5,3333 días hábiles, superior a la meta de cinco días. La velocidad promedio de brigadas para distancias iguales fue de 33,3333 km/h, calculada mediante la media armónica. La tasa anual compuesta de crecimiento de la recaudación fue de 8,3694 %. El promedio ponderado de trámites fue de 12,4667 por funcionario. La tasa armónica ponderada de procesamiento fue de 5,9259 expedientes por hora, sujeta a la condición de exposición comparable. El crecimiento geométrico promedio de la cobertura fue de 6,1535 %. El gasto mensual estimado por habitante fue de $342.500 y el crecimiento geométrico aproximado de los ingresos fue de 7,6607 %.

Conclusión administrativa. Las medidas de tendencia central permiten sintetizar información para apoyar decisiones de planeación, seguimiento y evaluación. La selección de la media debe responder a la naturaleza del indicador: tiempos y cantidades aditivas, tasas bajo condiciones de exposición comparables o factores de crecimiento. Los resultados deben acompañarse de unidades, supuestos y contexto institucional para evitar interpretaciones equivocadas.

Limitaciones. Los datos son simulados. Además, en los ejercicios 7 y 8 se sustituyeron los valores individuales por marcas de clase. En el ejercicio 5, la interpretación de la media armónica como tasa operativa exige que la exposición de las jornadas sea comparable; si no lo es, se necesitan los tiempos o exposiciones efectivos.

Conclusiones generales

  1. La media aritmética es apropiada para promediar cantidades comparables con igual peso o con ponderaciones explícitas.
  2. La media armónica es especialmente útil para promediar velocidades cuando las distancias son iguales y para tasas cuando la estructura de exposición lo justifica.
  3. La media geométrica es la medida adecuada para resumir factores positivos de crecimiento acumulativo.
  4. En tablas de frecuencias, omitir las frecuencias cambia el peso de las observaciones y puede producir un promedio incorrecto.
  5. En datos agrupados por intervalos, la marca de clase facilita el cálculo, pero introduce una aproximación.
